# Laravel Bootstrap Folder

## Purpose and area

This is a **Laravel backend startup/configuration** folder. It tells Laravel how to create the application, register routes, configure middleware, and load application providers.

## Existing files developers edit

- `app.php` registers web, API, console, and health routes and assigns middleware aliases: `firebase.auth` (FirebaseAuth), `admin` (AdminMiddleware), and `registered` (EnsureRegisteredUser).
- `providers.php` lists application service providers.

The `cache` subfolder is generated by Laravel and must not be manually documented or edited. Developers only change the startup files here when routing, middleware registration, exception handling, or providers require it.

## Example

When creating a reusable role-checking middleware, add its class under `app/Http/Middleware` and register a readable alias in `bootstrap/app.php`.

## Beginner mistakes to avoid

- Do not edit `bootstrap/cache`; Laravel regenerates it.
- Syntax errors here can prevent the entire application from starting.
- Register middleware here, but place the middleware's actual behaviour in `app/Http/Middleware`.
